#  【作品を付け足すには】
#   1. 動画（または画像）を assets/works/ フォルダに入れる
#   2. このファイルの下のほうにある「作品」のかたまりを
#      まるごとコピーして、いちばん下に貼る
#   3. 名前・英語・素材・説明の4つを書き換える
#   4. 「画像を反映して書き出す.command」をダブルクリック

#  【素材について】
#   ・動画（.mp4 .mov .webm）でも、画像（.jpg .png）でもよい
#   ・[素材] にはファイル名だけ書く（フォルダ名は書かない）
#   ・動画は音が出ません（作品として静かに流れます）
#   ・同じ名前で「◯◯-poster.jpg」を置くと、読み込み前にその絵が出ます
#     （なくても動きます）
#
#  【ルール】
#   ・[ ] の行は変えない。その下の文章だけ書き換える
#   ・[作品] が出てくるたびに、新しい作品として扱われます
#   ・行のあたまが # の行は説明。消しても残してもよい

[作品]
宇宙ハンド

[英語]
COSMIC HAND ― 3DCG / 映像

[素材]
cosmic-hand.mp4

[説明]
暗闇のなかで、手がひとつの球体へ手をのばす。爪にのせた色は、身体のいちばん外側にありながら、内側の気配を映す膜になる。触れる／触れないの、ほんのわずかな距離に、共感のはじまりを置いた。


[作品]
思唯手

[英語]
THINKING HAND ― エッチング風レンダリング / 映像

[素材]
thinking-hand.mp4

[説明]
量感をもった手が、線の集積へと還っていく。塗りを剥がし、輪郭と陰影だけを残すことで、身体が「かたち」ではなく「痕跡」として立ちあがる。物質としての手と、記号としての手のあいだを行き来する。

[作品]
白球

[英語]
WHITE ORB ― 3DCG / 映像

[素材]
white-orb.mp4

[説明]
爪の面と、ひとつの白い球。回りつづける球体に爪が寄り添うことで、身体の一部が天体のようなものと同じ速度で動きだす。


[作品]

NAIL FITTING ― インタラクティブ / 記録映像

[素材]
